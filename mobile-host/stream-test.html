BOOKWORM-PROVEN TRANSPORT

長篇鎖屏串流測試

一次啟動、一個媒體 element、一條持續 append 的 MP3 timeline。這個頁面只驗證播放框架；Piper 或其他 TTS 只需替換 segment producer。

此瀏覽器不支援 audio/mpeg MediaSource，無法執行這項測試。

ARCHITECTURE

與產品 TTS 的接點

  1. 1
    Producer

    逐句回傳 { buffer: ArrayBuffer, meta }；實機版本在這裡接 Piper Worker 與 MP3 encoder。

  2. 2
    Sequence append

    SourceBuffer.mode = "sequence"，所有片段合併為同一條時間軸。

  3. 3
    Event-driven refill

    sourceopen、startstreaming、updateend、timeupdate 與 waiting 都能補產。

  4. 4
    Bounded memory

    ahead 目標 90 秒，保留約 30 秒已播放音訊，再分批裁切舊 buffer。

IOS CHECK

實機驗收步驟

  1. 以 HTTPS 開啟並加入主畫面。
  2. 按「開始連續串流」，等 buffer 超過 30 秒。
  3. 鎖屏並確認系統播放／暫停控制可用。
  4. 至少播放 2 小時，跨越多個模擬章節。
  5. 解鎖後確認 Underflow 仍為 0，flight recorder 在 hidden 期間持續 append。
